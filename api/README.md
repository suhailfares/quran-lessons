### After cloning make sure that python is installed on ur device and add it to PATH variables (in the options of installer)

- python -m venv env   --> creates an environment folder 
- .\env\Scripts\activate.ps1   --> activates the environment
- pip install -r requirements.txt   --> downloads dependencies
- python manage.py migrate   --> migrates the db (if one is chosen, db.sqlite3 autogenerated by default, not production db)
- python manage.py runserver   --> runs the server

## Quran Seeders (only first time after the connection WITH A NEW AND EMPTY database has been made, like a local one)
- python manage.py seed_data
- python manage.py seed_quran
